# 🌌 MATRIX GALAXY

**MATRIX GALAXY** es un emocionante juego en 3D desarrollado con tecnologías web modernas. En este universo, tomas el control de un **Programador** que debe sobrevivir en planetas de estilo voxel, enfrentándose a "bugs" del sistema y compilando niveles para avanzar.

## 🚀 Tecnologías Utilizadas

Este proyecto aprovecha la potencia de las últimas herramientas de desarrollo web:

- **[React 19](https://react.dev/):** Biblioteca principal para la interfaz de usuario.
- **[Three.js](https://threejs.org/) & [React Three Fiber](https://r3f.docs.pmnd.rs/):** Motor de renderizado 3D de alto rendimiento.
- **[Tailwind CSS](https://tailwindcss.com/):** Estilizado moderno y responsivo.
- **[Framer Motion](https://www.framer.com/motion/):** Animaciones fluidas e interactivas.
- **[TypeScript](https://www.typescriptlang.org/):** Tipado estático para un código más robusto y mantenible.
- **[Vite](https://vitejs.dev/):** Herramienta de construcción ultra rápida.

## 🎮 Características del Juego

- **Planeta Voxel Dinámico:** Generación de mundos basados en cubos con física integrada.
- **Sistema de Combate:** Enfréntate a enemigos (bugs) utilizando habilidades de disparo y movimiento.
- **Interfaz Futurista:** UI diseñada con estética "Matrix" y efectos de post-procesamiento (Bloom, Vignette).
- **Sistema de Audio:** Efectos de sonido integrados para una experiencia inmersiva.
- **Progresión de Niveles:** Supera 10 niveles de dificultad creciente antes de que el tiempo se agote.

## 🛠️ Instalación y Ejecución

Sigue estos pasos para ejecutar el proyecto en tu entorno local:

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/juanmenaz/juego-de-prueba.git
   cd juego-de-prueba
   ```

2. **Instala las dependencias:**
   ```bash
   npm install
   ```

3. **Configura las variables de entorno:**
   Crea un archivo `.env.local` en la raíz del proyecto y añade tu clave de API si es necesaria (por ejemplo, para funciones de IA):
   ```env
   GEMINI_API_KEY=tu_clave_aqui
   ```

4. **Inicia el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

5. **Abre tu navegador:**
   Visita `http://localhost:3000` para empezar a jugar.

## 🕹️ Controles

- **W, A, S, D / Flechas:** Movimiento del personaje.
- **Espacio:** Saltar.
- **Shift:** Dash (Impulso).
- **E / Enter:** Disparar.
